Divide y vencerás

Una DFT de N puntos se separa en una DFT de las muestras pares y una DFT de las muestras impares. Luego se recombinan con factores twiddle.

X[k] = E[k] + W_N^k O[k]
X[k+N/2] = E[k] - W_N^k O[k],   0 <= k < N/2
La demo usa radix-2, por eso N debe ser potencia de dos. Otras FFT existen para tamaños compuestos o mixtos, pero la idea de reutilizar subproblemas es la misma.

Conteo de operaciones

En radix-2 hay log₂(N) etapas, N/2 mariposas por etapa, una multiplicación por twiddle y dos sumas complejas por mariposa.

Pseudocódigo de la versión iterativa

reordenar x[n] por inversion de bits
para m = 2, 4, 8, ..., N:
  para cada bloque de largo m:
    para j = 0, ..., m/2 - 1:
      u = a[p + j]
      v = W_m^j a[p + j + m/2]
      a[p + j] = u + v
      a[p + j + m/2] = u - v
